# 🤖 Mini Robot Inteligente

Proyecto de construcción de un pequeño robot desarrollado desde cero con Arduino, electrónica y programación.

Este proyecto forma parte de la serie **Mini Robot Inteligente** del canal **INVENTOS Y PROYECTOS**, donde se muestra paso a paso el proceso de diseño, construcción, programación y pruebas del robot.

## 🚀 Características

El robot irá incorporando progresivamente diferentes funciones, entre ellas:

* 👀 Pantalla OLED con ojos animados
* 👂 Movimiento de orejas
* 🛞 Movimiento mediante motores
* 📏 Sensores para detectar el entorno
* 🎤 Entrada de audio
* 🔊 Reproducción de sonidos
* 🧠 Control mediante microcontrolador

> El proyecto se encuentra actualmente en desarrollo y las características pueden cambiar durante su construcción.
